# 🐱‍👤 Pokédex

Uma Pokédex desenvolvida com HTML, CSS e JavaScript utilizando a PokéAPI.

## 🚀 Funcionalidades

- Buscar Pokémon por nome ou número
- Exibir imagem oficial
- Mostrar tipos
- Exibir altura e peso
- Interface simples e responsiva

## 🛠 Tecnologias

- HTML5
- CSS3
- JavaScript
- Fetch API
- PokéAPI
